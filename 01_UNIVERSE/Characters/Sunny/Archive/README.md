## Purpose

This folder stores superseded Sunny character references, generation specifications, and other historical character assets.

## Archive Rules

- Do not place active canonical references in this folder.
- Do not use archived assets as the current character reference.
- Archived assets must remain traceable to their character and reference version.
- Archived versions must never silently replace the active character design.
- Do not delete canonical history without explicit project approval.

When a canonical character version is superseded:

3. Update the active Character Bible and active package where required.
4. Move superseded assets into this archive when appropriate.
5. Preserve traceability between the active and archived versions.
6. Never silently replace or modify a canonical character identity.
