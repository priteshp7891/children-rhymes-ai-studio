## Purpose

## Character Authority

The character authority chain is:

Character Universe
→ Individual Character Bible
→ Character Generation Standard
→ Canonical Character Reference
→ Character Master Generation Prompt

The Character Universe defines who belongs to the canonical cast.

Individual Character Bibles define each character's identity.

Canonical references define the approved visual appearance.

Scene-specific instructions must not redesign a canonical character.

## Character Identity Rule

A generated scene may change:

- action
- pose
- expression
- environment
- lighting
- camera
- staging

A generated scene must not silently redesign:

- character identity
- locked visual DNA
- canonical proportions
- canonical clothing
- canonical signature elements
- canonical reference appearance

Any intentional character-design change requires an explicit character-design revision.

## Canonical Reference Standard

Each character's `REF-001` reference chain is authoritative for production.

Generated scene assets do not automatically become canonical character references.

A new canonical reference requires explicit approval and a character-design revision.

## Production Resolution Standard

Every scene containing a canonical character must resolve that character through:

`Character Invocation → Character ID → Reference ID → Character Bible → Canonical Reference`

Unresolved or contradictory character identity is a production validation failure.

## Revision Policy

This document is CANONICAL / LOCKED.

Changes to the canonical cast, character IDs, or reference IDs require an explicit universe revision.

Changes to an individual character's visual identity require an explicit character-design revision and must not be silently introduced through scene production.
